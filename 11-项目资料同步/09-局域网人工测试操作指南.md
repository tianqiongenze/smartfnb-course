# smartfnb 局域网人工测试操作指南

> 适用对象：测试人员/业务验收人员（局域网内任意 PC，无需安装任何开发工具）
> 环境：10.167.2.175 / 10.167.2.176 K8S 集群（fnb-prod）
> 前置：电脑与服务器在同一局域网；浏览器 Chrome/Edge 均可

## 二、测试前准备（5分钟）

1. 打开管理端 http://10.167.2.175:30250 ，确认页面顶部显示"🍽️ 智慧餐链"且无报错弹窗；
2. 确认"差异看板"菜单出现三个菜单项：用量差异看板 / 智能体助手 / 运营决策；
3. 记下当天日期（测试数据最新到 2026-10-25，**日期选择不要晚于该日**）。

## 三、测试用例（按顺序执行，每项记录 通过/失败 + 截图）

### TC-01 差异看板加载（约2分钟）
1. 进入"📊 用量差异看板"；
2. 门店下拉选"7-粤味轩07号店"，日期选 **2026-10-23**，点【查询】；
3. ✅ 预期：顶部出现"预警 N 条"，中间表格显示食材/品类/理论(kg)/实际(kg)/差异率/级别，多行为 HIGH。

### TC-02 预警人工确认
1. 在"预警列表(可确认)"中点击任意一行的【确认】；
2. ✅ 预期：该行状态变为"已确认"，刷新后仍保持。

### TC-03 智能体对话（核心）
1. 进入"🤖 智能体助手"，门店选 7，日期选 2026-10-23；
2. 输入：`7号店牛肉用量差异`，发送；
3. ✅ 预期：出现"[置信度:HIGH]"标签与差异报告（含"数据来源: MCP工具get_diff, SQL可溯源"字样、具体 kg 数字）；
4. 再输入：`预测7号店下周鲈鱼的需求`；
5. ✅ 预期：返回预测类回答（可能较慢，10-60秒属正常，CPU 推理）；
6. ⚠️ 注意：门店/日期以页面下拉与日期框为准，文字中的"2号店"等不改变查询范围（已知项 D-08）。

### TC-04 运营决策页
1. 进入"🧭 运营决策"；
2. ✅ 预期：采购审批 / 质量门禁 / 预测区间(CI) 图能正常展示（无数据时显示空态也算通过，不报错即可）。

### TC-05 H5 门店领料（全链路写入）
1. 手机或浏览器打开 http://10.167.2.175:30254 ；
2. 门店选 7，食材任选（如 IMG-0001 牛柳），类型选"领料消耗"，数量填 2.5，单位"千克"；
3. 点【✓ 确认登记】；
4. ✅ 预期：页面提示"已登记 consume 2.5kg(换算2500克) 成功"；
5. 回到管理端差异看板查询当日数据，该食材"实际"用量应增加约 2.5kg（若当日已有数据）。

### TC-06 H5 会员页
1. 打开 http://10.167.2.175:30255 ；
2. ✅ 预期：页面可打开、无 5xx。

### TC-07 GraphQL 接口（可选，验证 BFF）
1. 打开浏览器开发者工具(F12) → Console，执行：
   ```js
   fetch('/graphql',{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify({query:'{stores{id,name,city}}'})}).then(r=>r.json()).then(d=>console.log(d))
   ```
2. ✅ 预期：返回 32 家门店列表。

## 四、常见问题

| 现象 | 处理 |
|---|---|
| 页面打不开 | 确认在局域网内；ping 10.167.2.175；VPN 用户需接入内网 |
| 智能体回答为空 | 刷新页面重试；若仍空，联系管理员确认 svc-portal 版本 ≥0.1.3、web-admin ≥0.1.5 |
| 差异数据为空 | 日期选了 2026-10-25 之后（无数据），改为 2026-10-23 |
| 预测很慢 | 正常（CPU 推理 10-60s）；超 2 分钟报错请截图反馈 |
| 领料登记失败 | 检查数量为正数；确认类型已选择（默认"领料消耗"） |
