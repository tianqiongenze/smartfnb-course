## 二、双元制课程结构（64学时）

```
每周4学时 = 校内理论2学时 + 企业/实训实践2学时
16个单元：复盘导入 → 需求 → 架构 → 选型 → 数据 → 智能体 → 测试 → 压测 → 部署 → 重构 → 答辩
```

## 三、学习方法（学生必读）

1. **课前**：从本仓库拉取最新课件与任务书；
2. **课中**：理论认真听，费曼环节必须开口讲；
3. **课后**：完成实训任务+布鲁姆题+费曼卡片，按时提交；
4. **企业实践**：遵守安全保密要求，企业导师评分占60%。

## 四、资料同步机制

- 本课程依托的项目仓库：`smartfnb-agent-platform`（Private）；
- **项目任何更新（文档/代码/报告）将同步至本仓库对应单元资料**（见 `tools/sync_course.sh`）；
- md 均已转换为 Word 与 PDF 各一套，方便离线分发（见 `10-文档转换/`）。

## 五、考核

平时10% + 实训任务30% + 阶段项目25% + 期末答辩25% + 文档作品集10%；企业导师与企业评价占实践部分60%。
