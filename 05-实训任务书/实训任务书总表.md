# 实训任务书总表（任务0-6）

> 双元制实践任务包。每任务含：目标、步骤、交付物、评分标准（详见06-评价量规）。企业任务由企业导师主持评分（占60%）。

---

## 任务0：AI项目失败复盘诊断（第1周，校内）

- **目标**：理解反模式P1-P7，建立工程敬畏。
- **步骤**：① 阅读复盘案例材料；② 分组列出项目失败的所有原因；③ 将原因归类到7大反模式；④ 为每个反模式写出对应防线。
- **交付物**：《反模式诊断表》1页/人。
- **评分**：归类准确40% + 防线可行40% + 表达20%。

## 任务1：需求规格说明书（第2周，企业案例）

- **目标**：把业务诉求写成可量化、可验收的需求。
- **步骤**：① 确定业务范围与角色；② 写百万口径5项指标；③ 写功能/非功能需求；④ 写3条以上可量化验收标准；⑤ 声明数据依赖与降级路径（反P6）。
- **交付物**：《需求规格说明书》1份/组（md+Word+PDF）。
- **评分**：口径量化30% + 验收标准可测40% + 数据依赖声明30%。

## 任务2：技术选型与ADR（第4周，企业）

- **目标**：基于约束做选型并用ADR记录决策。
- **步骤**：① 列出约束（团队/运维/成本/兼容性）；② 给出候选方案对比；③ 决策并写ADR（背景/决策/后果）；④ 组间互评。
- **交付物**：ADR 1条/人。
- **评分**：约束分析30% + 决策合理40% + 后果诚实30%。

## 任务3：亿级数据生成与质量核验（第6周，企业为主）

- **目标**：掌握数据资产评估与亿级模拟数据生成。
- **步骤**：① 设计数据模型（门店/商品/订单/消耗/库存）；② 运行生成脚本产出亿级数据；③ 执行数据质量9项核验；④ 输出核验报告。
- **交付物**：数据字典+质量核验表。
- **评分**：数据可用40% + 核验完整40% + 报告规范20%。

## 任务4：Agent Harness收紧实验（第8周，校内实训）

- **目标**：理解并调优智能体Budget/Context/Loop/Eval。
- **步骤**：① 部署基础智能体；② 收紧budget（max_llm_calls 6→3）观察行为；③ 跑100条eval评审集；④ 对比token消耗与正确率。
- **交付物**：实验报告（前后对比数据）。
- **评分**：实验设计30% + 数据真实40% + 结论分析30%。

## 任务5：MCP工具+A2A对话（第10周，企业）

- **目标**：掌握MCP工具注册与A2A智能体互操作。
- **步骤**：① 用FastMCP写1个业务工具（含参数校验与_sanitize）；② 注册到智能体并调用成功；③ 配置AgentCard；④ 完成两个智能体message/send对话。
- **交付物**：工具代码+A2A对话截图。
- **评分**：工具可用40% + A2A打通40% + 代码规范20%。

## 任务6：全量压测与优化（第13周，实训）

- **目标**：掌握K6+Locust压测与性能分析。
- **步骤**：① 设计压测场景（至少3个）；② 跑五档梯度+1万并发；③ 记录RPS/p95/错误率；④ 找出饱和点；⑤ 提出并验证至少1项优化。
- **交付物**：压测报告+优化前后对比。
- **评分**：场景设计30% + 数据严谨40% + 优化有效30%。
