# 评价量规（Rubric）

> 适用：实训任务、阶段项目、期末答辩。双元制双主体：企业导师60% + 校内教师40%（答辩为双评委均分）。

---

## 一、实训任务通用量规（每任务100分）

| 维度 | 权重 | 优秀(90-100) | 良好(75-89) | 合格(60-74) | 不合格(<60) |
|---|---|---|---|---|---|
| 任务完成度 | 40 | 全部步骤完成且可复现 | 完成90% | 完成70% | 低于70% |
| 数据/结论真实 | 30 | 全量真实数据，诚实报告失败 | 基本真实 | 有选择性展示 | 樱桃数据/造假 |
| 规范性 | 20 | 命名/格式/文档符合模板 | 少量偏差 | 明显随意 | 无规范 |
| 费曼表达 | 10 | 讲解清晰、让外行听懂 | 基本讲清 | 照稿念 | 讲不清 |

## 二、期末项目答辩量规（100分）

| 维度 | 权重 | 评价要点 |
|---|---|---|
| 技术实现 | 40 | 架构合理、功能可演示、有测试证据（功能通过率+压测数据） |
| 工程规范 | 30 | 需求/设计/ADR/测试报告文档齐全（Word+PDF）、Git提交规范 |
| 演示与表达 | 20 | 15分钟内完整演示、答辩应答准确 |
| 创新与反思 | 10 | 有自己的优化/重构点，能反思失败教训 |

## 三、双元制企业实践评价表（企业导师填写）

| 项 | 5分制 | 说明 |
|---|---|---|
| 出勤与职业态度 | | 按时、主动、守纪 |
| 任务执行 | | 独立完成度、遇到问题的处理 |
| 团队协作 | | 沟通、互助、责任担当 |
| 成果质量 | | 交付物可用性与规范性 |
| 安全与保密 | | 数据安全、内网信息保护意识 |

## 四、布鲁姆分层评价锚点

| 层级 | 达标表现（答辩中观察） |
|---|---|
| 记忆 | 准确说出术语与协议名称 |
| 理解 | 用自己的话解释原理（费曼） |
| 应用 | 现场演示功能操作 |
| 分析 | 解释压测/缺陷数据背后的原因 |
| 评价 | 说明选型/重构的理由与取舍 |
| 创造 | 展示超出课堂要求的自主设计 |
