## 三、分课次详细计划

> 每周 4 学时拆为「第 1-2 学时（理论/演示）」+「第 3-4 学时（实训/企业/费曼）」。

### U01 课程导入与 AI 项目死亡复盘

- **教学目标**：理解 AI 项目失败原因；掌握反模式前置防线。
- **学时内容**：
  - 第 1-2 学时：课程导论、项目全景、失败案例拆解（签单 120 万→退款道歉重来）。
  - 第 3-4 学时：讨论"如果重来怎么做"，总结 7 大反模式。
- **费曼 5 分钟**：用自己的话复述一个反模式。
- **作业**：实训任务书任务 0。

### U02 需求分析与百万级口径、数据要敏感

- **教学目标**：把业务诉求写成可量化的需求；理解数据要敏感。
- **学时内容**：
  - 需求要素、百万口径 5 项指标；数据资产的提前意识。
  - 实训：撰写需求规格说明书初稿。
- **费曼**：解释"只承诺业务结果，不承诺技术细节"。

### U03 TOGAF 总体架构 + DDD/CQRS

- **教学目标**：掌握四架构域与领域建模。
- **学时内容**：
  - TOGAF ADM、业务/数据/应用/技术架构；限界上下文、六边形、CQRS。
  - 实训：绘制总体架构图（mermaid）。
- **费曼**：用比喻讲解"为什么分层"。

### U04 技术栈选型与 ADR 决策

- **教学目标**：能基于约束做技术选型并记录决策。
- **学时内容**：
  - Java21+SpringBoot3（Undertow 弃 Tomcat）、Python Litestar（弃 FastAPI/Granian）、Vue3。
  - 实训：为一个模块做选型并写 1 条 ADR。
- **费曼**：解释弃用某个技术栈的原因。

### U05 数据架构：TiDB 读写分离 + 多级缓存

- **教学目标**：理解 HTAP、读写分离、L0-L4 缓存。
- **学时内容**：
  - TiDB 原理、Caffeine/Redis/Milvus 语义缓存；Redis 集群 warmup。
  - 实训：配置 Redis 集群并验证 warmup 命中。
- **费曼**：讲清"为什么缓存分三级，数据在每级怎么流动"。

### U06 Phase0 数据资产评估 + 亿级数据生成

- **教学目标**：掌握数据质量核验；能生成并评估亿级数据。
- **学时内容**：
  - 数据资产评估 9 项、1.34 亿行数据生成；防樱桃数据。
  - 实训：运行数据生成脚本并做质量抽检。
- **费曼**：说明"签约前为什么要先评估数据"。

### U07 TDD/BDD/SDD 测试驱动开发

- **教学目标**：掌握 TDD 红绿重构、BDD Gherkin、SDD 契约。
- **学时内容**：
  - pytest/JUnit、Gherkin 场景、契约先行。
  - 实训：对一个接口做 TDD 全流程。
- **费曼**：举"红灯→绿灯→重构"例子。

### U08 Agent Harness 工程化

- **教学目标**：理解智能体工程化四要素。
- **学时内容**：
  - Budget/Context/Loop/Eval；LangGraph 多智能体路由。
  - 实训：收紧智能体预算并跑通 100 条评审集。
- **费曼**：解释"为什么智能体需要预算与循环上限"。

### U09 RAG 检索 + 语义缓存（防幻觉）

- **教学目标**：掌握 RAG、语义缓存、防幻觉三件套。
- **学时内容**：
  - Milvus 语义检索、crc32 哈希嵌入、工具直答+数字溯源+数值守卫。
  - 实训：实现语义缓存并验证 1s 命中。
- **费曼**：讲清"如何让智能体不编造数字"。

### U10 MCP 协议 + A2A 智能体互操作

- **教学目标**：掌握 MCP 工具开发与 A2A 交互。
- **学时内容**：
  - MCP Streamable-HTTP、12 工具开发；AgentCard、message/send。
  - 实训：注册 MCP 工具 + 两个智能体 A2A 对话。
- **费曼**：区分 MCP（工具协议）与 A2A（智能体间协议）。

### U11 事件驱动架构 + Pulsar

- **教学目标**：掌握消息中间件与领域事件。
- **学时内容**：
  - 事件驱动、Pulsar 生产消费者、库存预警。
  - 实训：实现事件预警（0.3s 响应）。
- **费曼**：解释"事件驱动相比接口调用的价值"。

### U12 功能测试：43 用例六域

- **教学目标**：能设计并跑通功能测试，管理缺陷。
- **学时内容**：
  - 用例设计（Harness/事件/语义/世界模型/A2A/业务六域）、缺陷 D-01~D-04。
  - 实训：按测试报告跑通 43/43。
- **费曼**：复述一个缺陷根因。

### U13 性能压测：K6 + Locust 全梯度

- **教学目标**：能设计压测场景、读取并分析性能数据。
- **学时内容**：
  - K6 七场景、Locust 混合旅程、五档梯度+1 万/10 万并发。
  - 实训：跑压测、分析饱和点与优化清单。
- **费曼**：解读"为什么 10 万并发 0 错误但服务≈2.2K RPS"。

### U14 容器化 + K8S 部署运维

- **教学目标**：掌握 Docker 镜像、K8S yaml、监控告警。
- **学时内容**：
  - Deployment/Service/ConfigMap；Prometheus/Grafana/Loki；set env 陷阱。
  - 实训：编写并 apply 部署 yaml。
- **费曼**：讲解"为什么改配置要 revert 而不是 set env"。

### U15 综合集成 + 多视角审查重构（R1-R10/ADR）

- **教学目标**：能多视角审查、打分、重构。
- **学时内容**：
  - 招标师/前端/架构/AI/美工五视角；加权 7.10；R1-R10；ADR-0009~0015。
  - 实训：对自己项目做审查并写重构方案。
- **费曼**：讲清一个 ADR 的前因后果。

### U16 期末答辩 + 双元制成果汇报

- **教学目标**：能完整展示并答辩项目。
- **学时内容**：
  - 每组 15 分钟演示 + 答辩；双评委评分；课程总结与复盘。
- **费曼**：作为成果汇报分享"最难忘的坑与成长"。

## 五、实施说明

1. **双元制**：每周"理论(校内)→实践(企业/实训)"递进；企业导师参与 U06、U14 及答辩。
2. **费曼 5 分钟**：每单元必做，计入平时分。
3. **布鲁姆**：课后习题按六层梯度（见 09 题库），随进度下发。
4. **Git 同步**：所有 md 已转 Word/PDF，存放于 `10-课件转PDF/` 与对应目录；学生可从课程仓库实时拉取。
