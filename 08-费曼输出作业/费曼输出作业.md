# 费曼学习法输出作业

> 费曼学习法四步：①选定概念 → ②用最简单的话讲给外行听 → ③发现卡壳处回炉重学 → ④简化并类比。
> 每单元完成1次费曼输出，计入平时分。格式：费曼卡片（≤300字+1张图）。

---

## 一、费曼卡片模板

```
【费曼卡片】U__ 姓名：____ 学号：____
1. 我要讲的概念：__________
2. 讲给外行听（≤200字，禁用术语堆砌）：
   ________________________________
3. 我用的类比：__________
4. 卡壳的地方（回炉重学点）：__________
5. 简化后的最终版本（≤50字）：__________
```

## 三、课堂费曼环节规则

1. **两人互讲（3分钟）**：同桌互为外行听众，听不懂就提问；
2. **抽签上台（2分钟×3人）**：全班面前讲，教师只追问不打断；
3. **评分**：听众能复述=满分；听众茫然=回炉重来；
4. **费曼图谱**：期中/期末各交1张思维导图，把整门课知识连成网。

## 四、评分

- 卡片完成20% + 类比贴切30% + 卡壳反思30% + 台上表达20%。
